# Contributing to SYNTHIA

Thank you for contributing to SYNTHIA.

## Principles

- build reproducible worlds
- separate simulation truth from visual rendering
- version worlds, scenarios, seeds, and datasets
- keep the first milestone small and testable
- prefer modular architecture over monolithic implementation

## Workflow

1. Create a small feature branch
2. Keep commits focused and descriptive
3. Add or update documentation when behavior changes
4. Verify that the work aligns with the v0.1 milestone

## Development priorities

The current priority is to build the v0.1 foundation:

- procedural world generation
- terrain and roads
- buildings and vegetation
- first-person control
- vehicles and pedestrians
- sensors and dataset export

## Communication

Document major design decisions in the docs directory before implementing broad-scope changes.
